# GraphicPassword
Программа "Графический ключ для аутентификации". Учебныый проект(C#, Windows Forms)

Функционал:
- Позволяет пользователю нарисовать графический ключ (жестом)
- Сохраняет эталонный ключ
- Проверяет совпадение при повторном вводе
- Защита от подбора

Технологии:
- C# (.NET)
- Windows Forms
- GDI+ (рисование на PictureBox)
